# Group 14 README

This repository contains our group's submission for **Phase 1** of the CITS5501 Project.
This project involves prototyping a **terminal-based interface** for Koto Enterprises' *Tachi* travel reservation system.
Phase 1 focuses on repository setup, implementation and tsting the `DateTimeChecker` utility, and preparing a Software Quality Assurance (SQA) plan.

## 1. Overview

This phase of the project concentrates on:
- Setting up and managing a **private GitHub repository** with correct structure.
- Implementing `DateTimeChecker.java`, a class to validate dates and datetimes.
- Writing **JUnit Tests** in `DateTimeCheckerTest.java` to check both syntactic and semantic correctness
- Developing a **Software Quality Assurance (SQA) plan**

## 2. Getting Started

### 2.1 Prerequisites
- **Java Development Kit (JDK 11 or later)**
- **JUnit 5** for running tests

### 2.2 Installation
Clone the repository to your local machine:
```
git clone https://github.com/Jeremy-JR0/CITS5501-Project-Group14
```
